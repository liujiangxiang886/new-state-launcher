# 新起点启动器（New state launcher）

《机甲旋风》的**兼容启动器**：把玩家自备的游戏本体挂载起来，并提供扩展（mod）的安装、启用与冲突检查。

本项目**只包含启动器本身**，不包含游戏本体、不含游戏美术资源、不含反编译产物。

---

## 这个仓库里有什么

| 目录 | 内容 |
|---|---|
| `app/` | 启动器源码（UI、核心逻辑、PCK 读写、扩展挂载） |
| `tools/` | 构建、打包、校验、诊断脚本 |
| `tests/` | 测试用例（约 800 个） |
| `schemas/` | 配置与扩展清单的 JSON Schema |
| `docs/` | 使用手册、扩展规范、第三方许可归档 |
| `baseline/` | 仅 `identity-*.json`：本体指纹，用于判断玩家导入的是否为预期的版本 |
| `assets/ui/mecha/` | 界面素材的设计源图（版权归原权利人，见下节） |
| `扩展开发文档/` | 面向扩展作者的独立开发包 |

## 这个仓库里**没有**什么

- **游戏本体**。本体著作权归原权利人，需玩家自行准备。
- **游戏剧情与音频资源**。仓库不含剧情脚本、对话数据与音频。
- **兼容底座与引擎二进制**。`runtime/host*/`、`engines/*.exe` 均不入库（单文件超过 GitHub 100 MiB 限制）。

因此：**clone 之后可以直接读代码、跑测试、改界面，但无法直接启动游戏。** 完整运行需要下面「准备资源」一节的内容。

## 环境要求

- Windows 10/11 x64
- Python 3.13
- 依赖见 `requirements.txt`（PySide6 6.12 / pytest 9 / pyinstaller 6.12）

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## 从源码运行

```bash
python -m app.main            # 图形界面
python -m app.main cli stat   # 命令行
python -m pytest tests/ -q    # 测试
```

## 准备资源（完整运行所需）

启动器本身不含游戏数据，需要三类外部资源：

1. **游戏本体**：原版 `mchGame.exe`（内嵌 pck），或 4.7 剧情版的 `.pck`。在「游戏库 → 导入游戏本体」里登记，启动器只记路径，不复制、不修改。
2. **Godot 导出模板**：从 [godotengine.org](https://godotengine.org/download) 下载对应版本的 Windows 导出模板，放到 `engines/`。
3. **兼容底座**：`tools/build_base.py` 可以生成，但它需要一份**反解工程的 `project.godot`** —— 那份工程来自游戏本体，不在本仓库中，也不应随仓库分发。

第 3 项意味着：**没有反解工程的第三方无法从零复现可运行的底座。** 这是本项目的现状，不是配置问题。

## 设计要点

- **整包直挂**：导入本体后只登记路径，不解包、不复制、不改动原文件。
- **导入即待校验**：本体登记后状态为 `pending`，必须通过挂载冒烟才能启动。防止在包还没读完时启动、读到半截数据导致进程崩溃。
- **存档隔离**：启动时重定向 `APPDATA`/`LOCALAPPDATA` 到 `profiles/<档位>/appdata`，不碰原版存档。
- **双引擎线**：4.6（原版 1.45）与 4.7（剧情版）各自独立的底座、基线与扩展锚点。
