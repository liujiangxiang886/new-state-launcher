## 1.7 的三条核心变化

1. **mod 按线隔离**：4.6 与 4.7 的覆盖层、清单、启用状态、卸载完全独立；
   跨线安装硬拒绝；自定义线从第一版起按 `line id` 隔离存储。
2. **全基线源码兜底**：每条线随包带 `baseline/sources-<line>.zip`，启动器自动使用；
   用了补丁/钩子的包必须声明 `sources`（schema 4），缺源码直接拒装。
3. **状态语义明确**：首次导入「待插桩」是正常流程；启动成功后变「已就绪」，
   才代表钩子注册成功。
