## 新起点启动器 1.7 更新

### 最重要的三件事

**1. 4.6 和 4.7 的 mod 彻底分开了**

以前同一个扩展可能被装到两条线上，看起来能用、实际补丁打错位置。
1.7 起：

- 4.6 的包只能装 4.6，4.7 只能装 4.7，跨线直接拒绝；
- 两条线的启用/停用/卸载互不影响；
- 一个包支持两线时，作者会发两份，分别拖进对应版本即可。

**2. 所有基线都自带源码兜底**

启动器现在随包带每条线的反解源码（`sources-4.6.zip` / `sources-4.7.zip`），
打补丁与插桩时自动使用，**不需要你另外装源码工程**。

扩展作者的新包必须声明用的是哪份源码；对不上会拒绝安装——
这是为了防止「补丁锚点命中、改错位置」这种最难查的问题。

**3. 「待插桩」不是装坏了**

- 首次导入显示**待插桩**：文件装好了，钩子等启动时再插；
- 启动一次游戏、进程稳定 5 秒后变成**已就绪**：这才代表扩展真正生效；
- 启动后还是待插桩：看日志，把日志发给作者。

### 其他变化

- 卸载多线包时会问「只卸当前线 / 全部卸载」，不再一删全没；
- 扩展列表只显示当前线的包，切版本自动切换；
- 修正了「卸载后重启还在」的插桩缓存残留；
- 合集包允许部分成功，失败的成员单独提示原因；
- 4.7 剧情层替换会提示「按旧剧情源码算的补丁可能失配」。

### 升级注意

- 用**完整发布包**覆盖安装，不要只替换 exe——源码兜底层在 `baseline/` 里。
- 4.7 必须是标准本体（380,259 条目）；非标准改版会被源码指纹拦下。
- 升级后第一次启动稍慢（重建插桩缓存），之后恢复正常。

### 仍然不支持

联机 / P2P / 自建服务器。本启动器只做单机。
