# 玩家须知（新起点启动器 1.7）

> 第一次用先看这一页。三分钟能读完，能避开 90% 的「装了没用 / 进不去」。

---

## 1. 两个版本，两套 mod

启动器里有两条线：

| 版本 | 是什么 | mod 装在哪 |
|---|---|---|
| **4.6** | 1.45 原版 | 只对 4.6 生效 |
| **4.7** | 1.45 剧情版 | 只对 4.7 生效 |

**4.6 的 mod 不能装到 4.7，反过来也不行。** 启动器会直接拒绝，不是 bug。
一个扩展如果两线都支持，作者会发两份，分别拖进去即可。

同一份扩展在两条线的**启用/停用是分开的**：在 4.6 关掉，不会影响 4.7。

---

## 2. 装 mod 的标准流程

1. 先在左上角选好版本（4.6 或 4.7）。
2. 把扩展包（`.zip` / `.jjm` / `.pack`）拖进窗口，或点「导入扩展」。
3. 装完看扩展列表的状态：

| 状态 | 含义 | 你要做什么 |
|---|---|---|
| **待插桩** | 装好了，钩子还没插（**首次导入都这样**） | 启动一次游戏 |
| **已就绪** | 插桩成功，扩展真正生效 | 正常玩 |
| **已剔除** | 开发者模式判定它有问题 | 看提示，或换宽松档 |
| **不在此线** | 这个包不是当前版本的 | 切到对应版本 |

> **「待插桩」不是装坏了。** 插桩发生在启动游戏时；启动后进程稳定 5 秒，
> 状态会自动变成「已就绪」——那才代表成功。

4. 如果启动一次后**还是**待插桩：点日志看「找不到 xxx 的源码」或
   「方法名可能不对」，把日志发给作者。

---

## 3. 卸载 / 停用

- **停用**：文件保留，只是启动时不挂载。随时能再打开。
- **卸载**：删掉这条线的覆盖层。如果包同时装在两条线，会问你是「只卸当前线」
  还是「全部卸载」。
  - 只卸 4.6 不会影响 4.7；
  - 卸载后如果游戏还开着，先退出游戏再操作。

---

## 4. 存档

- 每条线、每个实例有独立存档目录，互不覆盖。
- 启动前会自动备份到存档目录的 `.history/<时间戳>/`，退出后对比变化。
- 导入别人的存档前也会先备份。
- **不要**手工删 `profiles/`；要清理用启动器里的存档管理。

---

## 5. 常见问题

| 现象 | 先做什么 |
|---|---|
| 装的时候提示「只适配 4.7」 | 切到 4.7 再装；不要跨线 |
| 装完进游戏没变化 | 看状态是否「已就绪」；仍是待插桩就看日志 |
| 启动黑屏 | 停用最近装的扩展，再启动；把日志发群里 |
| 提示「缺少可用的反解源码」 | 你的启动器包不完整，用完整发布包覆盖安装 |
| 提示「本体 pck 大小与随包源码不符」 | 你的 4.7 本体不是标准版；换标准本体 |
| 装了合集只成功一部分 | 1.7 允许部分成功；看哪几个失败、为什么 |
| 卸载后重启还在 | 扩展页点「清理残留」 |

---

## 6. 本启动器不做什么

- **不支持联机**：P2P / 直连 / 自建服务器 / 局域网联机一律拒绝。
- **不改你的存档**：只做备份与隔离，不修改游戏数据。
- **不替 mod 作者修包**：装不上就是装不上，日志里写原因。

---

## 7. 出问题怎么报

发这三样，作者/开发者能直接定位：

1. 启动器版本（设置页底部）；
2. 日志文件（`logs/` 下最新那份，或界面「导出诊断」）；
3. 你装了什么、在哪个版本线、状态显示什么。
