# me.minimal_companion

最小共存扩展 B。它依赖 A（`me.minimal`）、声明排在 A 之后加载，
但只写自己命名空间下的文件，所以和 A **不产生位置重叠**。

这两个包合起来就是「最小共存组合」：A 证明单包能过准入，
B 证明组合解析也能过准入。作者把自己的包加进来一起跑
`verify --with`，就能在发布前发现组合层面的冲突。

要点：

- `requires` 写精确范围并封上界，决定「B 离不开 A」；
- `load_after` 决定挂载顺序，**但它不消除冲突**——顺序要和位置避让一起用；
- 两个包改不同位置，才不会在开发者校验下被判重叠。

回退：停用 B 即可；A 不受影响。
