# 扩展开发文档（1.7）

给《机甲旋风》做扩展、改版接入所需的规范、工具与基线材料。

> **4.6 与 4.7 是两条完全独立的线**：源码、锚点、清单、安装目录、启用状态全部
> 分开。跨线安装会被硬拒绝，不要试图「一份包通吃」。
>
> 每条线的包都必须声明源码（`sources`）。启动器**自动**用随包源码兜底，
> 你不需要把原版脚本打进包。

## 三条最容易踩的坑

1. **拿 4.6 的锚点打 4.7**：`find` 可能照样命中，但改的是另一个函数。用
   `jjm_pack.py check --line 4.7` 对源码核一遍。
2. **不写 `sources`**：schema 4 会直接拒装；schema 3 放行但换台机器就可能
   「锚点命中、语义不对」。
3. **把「待插桩」当成失败**：首次导入就是待插桩；启动一次游戏、状态变「已就绪」
   才算成功。启动后仍是待插桩，才需要查日志。
