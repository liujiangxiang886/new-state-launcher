使用本软件产生的**全部风险由使用者自行承担**，包括但不限于：

### 3.1 存档风险

> **强烈建议**：在安装任何扩展前，自行额外备份

### 3.2 数据风险

启动器会读写以下位置：

- 自己的 `config/`、`profiles/`、`packs/`、`builds/` 目录

使用者应知悉这些路径的存在。因误删、误改、磁盘故障导致的数据丢失，
开发者不承担责任。

### 3.3 扩展风险

扩展由**第三方作者**开发，不是本软件的一部分。

开发者**不审核、不担保、不背书**任何扩展的内容、安全性或合法性。
安装来路不明的扩展可能带来：

- 游戏崩溃或存档损坏
- 恶意代码（扩展是以文本脚本形式注入的，理论上具备执行能力）

> **只安装你信任的作者提供的扩展。** 拿到来源不明的包，先解压看内容。

### 3.4 运行环境风险

启动器会启动游戏进程、读写文件、创建临时目录。
在受限环境（公司电脑、受管设备、沙箱）中使用前，
请确认符合该环境的使用规定。

### 3.5 系统内存优化（可选功能，默认关闭）

设置页的「启动优化 → 启动前释放系统内存」会在每次启动游戏前，
对**本机其它程序**调用 Windows 的 `EmptyWorkingSet`，把它们工作集里
暂时不用的物理内存页换出到页面文件。这是**系统级操作**，开启前请知悉：

- **它不降低游戏本身的内存占用。** 游戏进程永远不会被处理，
  退出后占用数字与未开启时一致；它只是给游戏多让出一些空闲物理页。
- 被换出的页在下次访问时需要重新读回。**机械硬盘**上可能出现
  「切回浏览器 / 微信时卡一下」，固态硬盘基本无感。
- 该操作只影响内存页的驻留位置，**不修改、不删除任何程序的数据**，
  也不会结束任何进程；但极端情况下（系统内存本就极度紧张 + 机械硬盘）
  可能造成短时的整体卡顿。
- 开关**默认关闭**，是否开启由使用者自行决定并承担相应体验变化。
  开发者不对开启后其它软件的性能表现、系统响应速度作出任何保证。

> 若你不确定是否需要，**保持关闭**。4.7 剧情版对物理内存的要求
> 不会因为这个开关而降低（见《运行要求》）。

### 3.6 自定义版本接入（改版创作者提供内容）

启动器为自定义游戏线提供「运行壳」与「接入壳」：登记时按**文件内容**
校验是否为 Godot 机甲旋风改版本体；创作者可随改版提供 `line.json` 描述
与反解工程索引，通过一致性校验后该线才升级为「可协商扩展」。使用前请知悉：

- 反解工程、源码、能力与锚点索引**全部由改版创作者自行提供**；
  启动器不生产、不逆向、不补全，也不为第三方改版本体的内容、版权、
  安全性或运行行为背书。
- 身份校验只回答「这是否为本家族的 Godot 改版本体」，**不构成**对该改版
  无恶意代码、无联机行为、不破坏存档的保证。
- 描述未通过一致性校验时，该线降级为仅启动、不加载扩展；通过校验也
  **不代表扩展必然兼容**，组合冲突仍需使用者自行验证。
- **不支持联机接入**：描述或扩展中声明、实现 P2P / ENet / WebSocket /
  UDP / TCP / DTLS 直连、自建服务端、IP:端口、NAT 穿透、局域网发现等
  联机协议或能力的，一律拒绝接入；启动器只做单机。改版本体自身携带的
  联机功能不在支持范围内，启动器不为其连接、数据或安全性负责。
- 因导入、运行第三方改版，或按其描述挂载扩展造成的存档、数据与系统问题，
  由使用者自行承担。
